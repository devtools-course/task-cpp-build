== Simple (5 points)

Subdirectory: `simple`

Create a script `build.sh`. It takes a single argument: output directory. The script must compile `main.cc` into `run` binary.

== Static library (5 points)

Subdirectory: `lib`

Create a script `build-static.sh`. It takes a single argument: output directory. The script must compile `moduleA` and `moduleB` sources into `devtools` static library. Put the library into the `_OUT_DIR_/lib` directory and its associated headers into `_OUT_DIR_/include`.

== Dynamic library (5 points)

Subdirectory: `lib`

Create a script `build-dynamic.sh`. It takes a single argument: output directory. The script must compile `moduleA` and `moduleB` sources into `devtools` dynamic library. Put the library into the `_OUT_DIR_/lib` directory and its associated headers into `_OUT_DIR_/include`.

== Compiling with libraries (5 points)

Subdirectory: `lib`

Create a script `multi.sh`. It takes a single argument: output directory. The script must compile `moduleA` sources into `moda` static library and `moduleB` sources into `modb` dynamic library. Put the libraries into the `_OUT_DIR_/lib` directory and their associated headers into `_OUT_DIR_/include`. Compile `use.cc` which depends on both libraries into `_OUT_DIR_/run` binary.

== Static linkage (10 points)

Subdirectory: `lib`

Create a script `runner.sh`. It takes a single argument: output directory. Use `build-static.sh` and `build-dynamic.sh` to create both dynamic and static variants of the `devtools` library. Now compile `use.cc`, which depends on `devtools`, into `_OUT_DIR_/run` binary. As you can see, the binary depends on the dynamic variant even though the static is present. Update the linker configuration so that it chooses the static variant.

TIP: Use `-Bstatic` and `-Bdynamic` linker options

== Using C code (10 points)

Subdirectory: `c-cxx`

Create a script `build.sh`. It takes a single argument: output directory. The `deps/deps.c` uses an old C standard: use `C89` to compile it. Compile all `.c` files according to the C ABI rules. Modify `main.cc` so that it can use the C code. The final binary must have name `run`.

== Header problems (10 points)

Subdirectory: `broken`

Create a script `build.sh`. It takes a single argument: output directory. The script must compile `main.cpp` into `run` binary. However, the headers have several problems: update their code so that the compilation succeeds.
